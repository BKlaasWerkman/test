# Snake

A classic Snake game in a single, dependency-free HTML file.

## Play

Open `index.html` in any modern browser.

- **Arrow keys / WASD** — move
- **Space** — pause / resume (or start)
- **Swipe** — move on touch screens

Eat the red food to grow and score points. The snake speeds up as you eat.
Hitting a wall or your own tail ends the game. Your best score is saved in the browser.
